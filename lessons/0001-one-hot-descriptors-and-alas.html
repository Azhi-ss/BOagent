为什么描述符之后，ALAS 才可能有意义

一个 8 分钟短课：不推导 GP，只建立足够准确的直觉，用来判断 BOagent 两个化学数据集的下一步。

核心：表示把化学对象画成一张地图；核规定观测产率如何沿地图传播。地图没有化学结构时，再灵活的核也不知道该往哪里传播。

1. One-Hot 把类别放成“等距岛屿”

Suzuki 溶剂 One-Hot 
DMF   = [1, 0, 0, 0]
MeCN  = [0, 1, 0, 0]
MeOH  = [0, 0, 1, 0]
THF   = [0, 0, 0, 1]

任意两个不同溶剂的欧氏距离都是 √2。表示只说“不同”，没说“怎样不同”。

连续描述符（示意，不是真实数值） 
DMF   = [极性, 供氢性, 受氢性, ...]
MeCN  = [极性, 供氢性, 受氢性, ...]
MeOH  = [极性, 供氢性, 受氢性, ...]
THF   = [极性, 供氢性, 受氢性, ...]

距离可以是 0.3、0.8、1.5……于是模型得到一张有层次的化学地图。

2. ALAS 学的是“距离—相关性曲线”的形状

忽略频率调制后，它的核心包络是：

相关性 k(d) = exp( - (d / ℓ)^α )

如果训练数据提供很多不同距离，模型才能比较：距离从 0.2 变到 0.6、再变到 1.4 时，产率相关性下降得平缓还是突然。这个下降形状就是 alpha 的信息来源。

但 One-Hot 每一位的差主要只有 0 或 1：0^α=0，1^α=1。在已有 ARD 长度尺度时，alpha 与长度尺度还会高度混淆。因此它很难被解释成“化学景观粗糙度”。

3. 指纹也是二进制，为什么仍然比 One-Hot 多信息？

类别 One-HotMorgan 指纹
一个 bit 表示“就是这个完整类别”某类局部原子环境/结构片段
两个分子比较只要名称不同就翻转类别位可能共享许多结构位，只差少量片段
常用相似度Hamming / equalityTanimoto：共享结构位占并集的比例

因此指纹能产生 0.15、0.62、0.91 等分级相似度。不过这不等于应该直接把每个 fingerprint bit 塞进 ALAS；更自然的第一基线是 Tanimoto 核。连续描述符或连续 embedding 才是 ALAS 最直观的输入。

4. 对 BOagent 更合理的组合

候选反应 x
  ├─ Electrophile → 结构表示 z_e → 分子核 k_e
  ├─ Nucleophile  → 结构表示 z_n → 分子核 k_n
  ├─ Ligand       → 结构表示 z_l → 分子核 k_l
  ├─ Base         → 描述符/类别核 k_b
  └─ Solvent      → 物化描述符核 k_s

总核 = 主效应
     + k_e × k_n        # 底物配对
     + k_l × k_b        # 配体-碱交互
     + k_b × k_s        # 碱-溶剂交互

其中某个连续分量可以用 Matérn、RBF 或 ALAS。采集仍然直接给有限候选池全部打分，所以不会生成不存在的“半个配体”或无效反应组合。

5. 不能忽略的风险

  • 结构相似不等于反应表现相似；反应机理可能造成 activity cliff。
  • 通用分子 embedding 未必编码配体电子/立体效应或溶剂作用。
  • IUPAC 名称、盐、金属配合物和 Nothing 必须可靠映射；Nothing 应有存在指示，不宜悄悄当全零普通分子。
  • 所有表示与超参数决策只能用公开结构、训练数据和逐轮已观测结果，不能查看未查询测试产率。
