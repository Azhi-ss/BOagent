架构核心逻辑

本系统采用 "统计筛选 + 物理先验融合" 的五层架构：

  1. 数据层 (DataLoader): 从 PVK-LLM Excel 数据集加载，按 Seed 确定性分割训练/测试集。
  2. 编排层 (BOStepEngine): 协调初始化、BO 循环、评估流程，支持多 Seed 并行对比。
  3. GP 筛选层 (Surrogate): 从数千候选中以 UCB/EI/PI 筛出 Top-20 "潜力股"。
  4. 物理先验层 (LLM Prior): 对 Top-20 逐点发起 Yes/No 物理可行性检查，提取 Log-probs 作为定量先验。
  5. 动态融合层 (Fusion): 自适应 λ_t 加权合并 GP 分数与 LLM 先验，平衡探索效率与物理正确性。
