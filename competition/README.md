## 一、赛题任务

在给定的离散候选反应条件空间中设计优化算法/智能体，在有限迭代轮数内选择实验候选点，尽快发现高产率反应条件。以干实验评测为主，在真实高通量实验的离线数据集上模拟闭环优化。

## 三、实验设置与轨迹输出要求

| 参数 | 设定值 |
| :--- | :--- |
| **每轮采样数** | 1 |
| **实验轮数** | 40 轮 |
| **重复次数** | 20 次独立运行 |
| **随机种子** | `100, 200, ..., 2000` |

### 优化轨迹输出要求
参赛队伍应为每个数据集、每个随机种子提交完整优化轨迹。建议以 `.pt` 文件保存每次 40 轮采样轨迹。每条轨迹应至少包含以下信息：
- 当前轮数；
- 本轮选择的候选实验条件 ID 或候选索引；
- 本轮观测到的目标值（Yield）；
- 截至当前轮的 best-so-far 值；
- *(必要时提供模型预测值、不确定性、采集函数值或推荐理由)*。

> ⚠️ **注意**：需在 `results_and_analysis` 中说明文件字段含义、读取方式和指标计算方式。

## 四、核心优化指标

所有指标按 20 次独立运行分别计算，报告均值、标准差和 95% 置信区间：

| 指标名称 | 含义说明 | 优化方向 |
| :--- | :--- | :--- |
| **首轮最大值** | 第一轮推荐后已发现的最佳 Yield。反映初始设计 / 热启动 / 先验知识利用质量。 | 越高越好 |
| **全程最优值 (`best_found`)** | 40 轮内发现的最高 Yield。衡量有限预算下最终发现能力的核心指标。 | 越高越好 |
| **突破轮数 (`t95`)** | 首次达到该数据集全局最优值 95% 的轮数。若预算内未达到则记为 `>40` 或按指定惩罚值计算。 | 越低越好 |
| **综合收敛曲线面积 (`AUC_best_so_far`)** | `best-so-far` 序列的累积/平均面积。同时体现早期探索和后续提升能力。 | 越高越好 |

## 六、评测机制与评分标准

### 6.1 阶段评审机制
实行 **“干实验初评 + 决赛专家问辩”** 两阶段评审：
- **初评阶段**：基于公开外部数据集（结合内部非公开数据集）进行干实验评测。
- **复评阶段**：晋级队伍进行专家问辩，评估真实场景下的应用价值。
- **综合总分**：晋级决赛队伍按 **初评 60% + 决赛问辩 40%** 加权；未晋级者按初评成绩排序。

### 6.2 初评维度与权重分配

| 评审维度 | 核心考量 | 权重比例 |
| :--- | :--- | :--- |
| **AI 方法设计与优化性能** | 算法设计、发现高产率条件能力、工程质量、环境可复现性及统计可信度 | **50%** |
| **研究方法的创新性** | 是否在策略、知识利用、数据利用或智能体设计上具备新意，缓解小样本/离散空间建模局限 | **15%** |
| **AI 可可行性** | 算法流程是否完整，训练/推理/推荐策略是否清晰，比赛周期内是否可落地 | **15%** |
| **科学合理性与可解释性** | 是否充分利用反应机理与领域先验，推荐结果是否具备化学合理性与可解释依据 | **10%** |
| **团队能力与跨学科配置** | 团队在 AI、化学、自动化实验等方面的跨学科背景及相关论文/开源/工程经验 | **10%** |

### 6.3 决赛问辩评分标准

| 评审维度 | 描述 | 权重比例 |
| :--- | :--- | :--- |
| **真实场景应用价值** | 面向真实化学研发/高通量实验场景的落地方案、变量理解、推荐解释及验证潜力 | **50%** |
| **方法创新性与科学理解** | 把握核心科学问题，相比传统 BO/RL 方法的原创性优势 | **10%** |
| **AI Scientist 闭环设计** | 展示 LLM/智能体在假设生成、理解、推荐、分析及迭代中的闭环作用 | **10%** |
| **结果解释与泛化潜力** | 能否解释关键推荐案例，方法迁移至其他反应类型的泛化能力 | **10%** |
| **工程实现与答辩表现** | 代码环境清晰可靠，答辩表达与专家提问回答质量 | **10%** |
